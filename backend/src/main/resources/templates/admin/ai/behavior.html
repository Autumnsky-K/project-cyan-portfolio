Function First

규칙은 프롬프트가 아니라 함수로 처리

01. 원본 DB 상품 / 아티스트 / 통계 / 재고 상태
  • LLM에게 주절주절 넣는 규칙 프롬프트가 아니라 함수가 읽을 원본 표
  • DB 요약과 검색 결과 행렬 JSON은 함수 결과로 생성
02. 로직 함수 목록 Hook / 요약 / 검색 / Memory / JSON 검증
  • 차단, 치환, count, TSV 요약, DBSearch, Memory 갱신은 함수 단계
  • LLM은 검색 키워드 선정과 최종 자연어 응답처럼 필요한 곳에만 사용
03. 관리자 설정 프롬프트 / 페르소나 / DOM / Motion / 출력 계약
  • 여러 파일로 쪼개지 않고 section 열로 설정 종류를 구분
  • DOM LIST와 Motion LIST도 같은 설정 TSV 안에서 관리
