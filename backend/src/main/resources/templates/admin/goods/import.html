이미지 폴더 규칙

기본 등록은 CSV와 로컬 이미지 폴더를 함께 올립니다. main.webp가 있으면 메인 이미지로 먼저 쓰고, 없으면 폴더 안 첫 번째 이미지를 메인으로 씁니다.

정렬순 5장까지는 이미지 슬롯에 들어가고, 6장째부터는 상세 설명에 이미지 HTML로 자동 첨부됩니다.

CSV의 이미지폴더가 비어 있으면 선택한 로컬 상품 폴더 대기열 순서대로 자동 배정됩니다.

수정 기준

상품ID가 비어 있으면 신규 등록, 값이 있으면 해당 굿즈를 수정합니다. 일괄등록 판매상태는 등록 후 검수할 수 있도록 HIDDEN으로 저장됩니다.

양식의 #로 시작하는 안내/예시 행은 업로드 시 무시됩니다. 괄호가 있는 값은 자유 입력 형식이고, 괄호가 없는 값은 DB 또는 선택 후보와 정확히 맞춰야 합니다.

업로드 대기열 CSV와 로컬 이미지 폴더를 선택하면 표시됩니다.
