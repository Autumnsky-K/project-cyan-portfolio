이미지 폴더 규칙

기본 등록은 CSV와 로컬 이미지 폴더를 함께 올립니다. 상품 폴더마다 main.webp, 1.webp부터 4.webp까지 매칭됩니다.

예: 업로드 폴더 안의 genshin/raiden/main.webp는 CSV의 이미지폴더 값 genshin/raiden와 일치해야 합니다.

수정 기준

상품ID가 비어 있으면 신규 등록, 값이 있으면 해당 굿즈를 수정합니다. 일괄등록 판매상태는 등록 후 검수할 수 있도록 HIDDEN으로 저장됩니다.

양식의 #로 시작하는 안내/예시 행은 업로드 시 무시됩니다. 괄호가 있는 값은 자유 입력 형식이고, 괄호가 없는 값은 DB 또는 선택 후보와 정확히 맞춰야 합니다.
